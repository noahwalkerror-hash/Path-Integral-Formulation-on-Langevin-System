# Memory-effects-in-thermodynamic-systems-with-variational-formulation
An individual research programme carried out during summer 2026 (May to August) that aims to extend the variational formulation into thermodynamical systems with memory effects.
-------------------------------------
Research Notes:<br>
1.Descriptions of time-continous ST systems: Langevin Equation, Fokker-Planck Equation, Path Integral formulation (Onsager-Mashlup)
2.Two parallel methods are taken against this question: 1.Fokker-Planck equation associated with Markovian embedding,take O-U noise as an example; 2. Path Integral formulation. Though the latter is more intuitive, a paper in 1989 have already taken that method with proper results (Hanggï,1989,Augsberg University).<br> 
3.However, the Hanggi paper does not include long-term memories' analysis in PI formulation. This could be used as an extension at some given time point.<br>
